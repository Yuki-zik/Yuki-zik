<details>
<summary><b>Data scope and refresh behavior</b></summary>

- The report defaults to the last 365 days in `Asia/Shanghai`. Manual runs can select a calendar year; the current year is year-to-date.
- Contributions are those visible through the configured GitHub token, not every commit across all accounts and private repositories.
- Repository details and language breakdowns are restricted to public repositories. Language proportions describe repository code bytes, not personal lines written.
- After the repair, Issue/PR counts represent public items **authored by me and created during the report period**. The older snapshot used a broader participation/updated-date query.
- Summary cards refresh daily and have their own scopes; their lifetime totals need not equal the rolling report.
- AI analysis is optional. Without its API configuration, a deterministic summary is used. Rendering failures keep the previous report and fail the workflow rather than publishing a blank image.

</details>
